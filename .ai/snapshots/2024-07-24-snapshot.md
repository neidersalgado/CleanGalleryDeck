## 2. Auditoría de Arquitectura

### 2.1 Estructura de Módulos

```
:app                           ← Entry point, Hilt, NavHost
:core:common                   ← Shared utilities
:core:domain                   ← Entities, VOs, Repos, Use Cases, MediaSource
:core:data                     ← Repo implementations, DataSources, DI, Registry
:core:analytics                ← Analytics (Firebase, via domain interfaces)
:core:notification             ← Notifications
:feature:deck                  ← DeckScreen, ViewModel (MVP)
:feature:settings              ← Settings (V2)
:feature:player                ← Media player (V2)
:media-sources:source-google-photos → Google Photos (V2)
:media-sources:source-local-images  ← Local images (MVP)
:media-sources:source-local-videos  ← Local videos (MVP)
```

### 2.2 Dependencias Corregidas

```
:core:domain           ← define MediaSource (interface)
↑                      ↑
:media-sources:google  ← implementa MediaSource
:media-sources:local   ← implementa MediaSource
↑                      ↑
:core:data             ← MediaSourceRegistry (inyecta Set<MediaSource>)
```

### 2.3 Patrón MVI

```
User Action → DeckIntent → ViewModel.handleIntent() → UseCase → Resource<T> → StateFlow<DeckState> → UI
```

### 2.4 Arquitectura de Observabilidad

```
:core:domain           ← AnalyticsService, CrashReporter, PerformanceTracer (interfaces)
↑                      ↑
:core:analytics        ← FirebaseTrackingService, FirebaseCrashReporter, FirebaseTracer
↑                      ↑
:app                   ← Hilt module binds interfaces → implementations
```

Domain y Feature nunca importan Firebase.

## 8. Concurrencia y Contratos

### Threading Model

| Dispatcher | Uso |
|------------|-----|
| `Main` | UI, StateFlow collection |
| `IO` | MediaStore, Room, disk |
| `Default` | CPU: filtering, sorting |

### Reglas

- Toda coroutine nace en `viewModelScope`.
- UseCases son `suspend fun` — sin scope management.
- Repositorios exponen `suspend fun` — nunca `Job`/`Deferred`.
- `supervisorScope` para operaciones paralelas independientes.
- Cancelación respetada en todo el grafo de llamadas.

### Feature Flags

```kotlin
enum class FeatureFlag(key: String, default: Boolean) {
    GOOGLE_PHOTOS("google_photos", false),
    STATISTICS("statistics", false),
    FILTER_BY_ALBUM("filter_album", false),
    EXPERIMENTAL_ANIMATIONS("experimental_anim", false),
    BATCH_SELECT("batch_select", false),
}
```

Default `false`. Almacenados en DataStore. UI reacciona via `StateFlow`.

## 13. Definition of Done (DoD)

Una tarea está completa SOLO si:
1. Sigue reglas de `RULES.md`
2. Tests unitarios >80% coverage en domain
3. Sin dependencias prohibidas (verificado con plugin)
4. `assembleDebug` + `test` + `lint` pasan
5. CI verde
6. ADR creado si hay decisión arquitectónica nueva
7. `.ai/` actualizado si cambia contexto
